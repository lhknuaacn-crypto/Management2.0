# 阅读指南

《管理学 2.0》从“执行者变了”这个前提出发，沿着管理学的经典问题推进：管理为何出现、组织怎样协作、目标如何衡量，直到授权、验证、学习和企业边界如何变化。

## 推荐顺序

从序章开始，按四部十六章读到尾声。每一章都回到一个管理问题，再讨论 Agent 进入工作流程后，旧答案哪些仍成立、哪些需要改写。

如果只想先看书的核心框架，可以从第 11 章“六环管理”开始，再读第 9 章“自治不是二元开关”和第 12 章“从 KPI 到证据链”。
