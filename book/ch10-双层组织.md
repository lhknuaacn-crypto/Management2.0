# 第 10 章　双层组织

先讲一个我自己的故事，一个亲手搭出来、也亲手搞砸过一次的系统。

过去一年，我给自己建了一套东西，二十多个 AI agent，各管一摊，有的看盘、有的写作、有的做研究、有的管硬件。要让这么多 agent 不打架、不各说各话，我很快撞上一个问题，规则往哪放。

一开始，我把所有东西都堆在一起，身份、规则、路由、当天的任务、临时的交接，全塞在同一个地方。结果是一团糟。高频变动的任务信息，把稳定的规则淹没了；想改一条规则，得在一堆当天的杂事里翻半天；agent 们经常读到过期的、自相矛盾的指令。

痛过之后，我做了一次拆分，把整个系统劈成两层。一层叫 00-Global，是宪法，放那些几乎不变的东西，每个 agent 是谁、有什么权限、路由规则、绝对不能碰的红线。它是唯一权威源，谁和它冲突以它为准。另一层叫 Harness-Exchange，是事件总线，放那些每天都在变的东西，谁派了什么任务给谁、干到哪一步了、交接的成品、验收的回执。它高频流动，但碰不到宪法。

拆完，整个系统清爽了，规则稳定地待在宪法层，不被日常的噪声冲刷；任务高速地在流动层跑，不必每次都惊动规则。后来我才意识到，这次痛过之后的拆分，撞上的正是一百年前马克斯·韦伯研究透了的东西，一个大组织靠什么在混乱中保持秩序。只不过我管的不是人，是 agent。

---

韦伯研究的问题是，一个庞大的现代组织，国家、大企业，凭什么能可预测地运转，而不依赖某个人的私人关系、家族特权或个人魅力。

他的答案叫理性法定权威，最纯粹的形态就是科层制，今天我们一听就皱眉的官僚制度。但韦伯的本意，和官僚主义那个贬义词，完全是两回事。他指出，科层制之所以强大，靠的是一套非人格的机制，清晰的职位和管辖范围、按能力选人、职位与私人财产分离、层级分明、靠成文规则和书面记录办事。它的好处是组织的运转不依赖任何具体的人，张三走了，李四接上，职位还在、规则还在、记录还在，组织照常运转。用韦伯的话说，官僚制行政的优越性，首要来源在于技术知识的作用，它带来精确、快速、明确、连续、审慎、统一。

韦伯也很清醒，科层制不是道德上无辜的。同一套带来可预测性的形式理性，也会压缩人的自由、让程序压过目的、把人变成机器上的一个齿轮。所以后来大家骂官僚主义，骂的是它的病态，不是韦伯说的那个内核。

但韦伯那个办事的人是人，一个能理解规则、能承担责任、能被问责和惩罚的人。他的整套科层制，建立在职位上坐着的是人之上。现在，职位上开始坐进 agent。

---

韦伯的科层制内核，用非人格的规则、身份、层级、记录来治理，而不依赖具体某个人，在 agent 时代不但没过时，反而是刚需中的刚需。

一个企业级的 agent，需要的正是韦伯那一整套的数字版，身份是这个 agent 是谁，角色和管辖是它管哪摊、不能碰哪摊，批准的工具是它能调什么，数据权限是它能看什么，决策阈值是多大的事它能自己定，日志是它干了什么全程可查，申诉路径是出了问题怎么上升。这些正是韦伯的职位、能力、文件、层级的一一对应。而且因为 agent 动作又快、成本又低，这套非人格的授权和完整记录，比管人时更重要，一个 agent 能在你没反应过来之前干完一百件事，你只能靠事前的规则和事后的日志来治理它。

但 agent 时代的科层，有一样韦伯做梦都想不到的东西。韦伯的规则，是写在纸上、靠人去读、靠人去遵守的。agent 时代，规则可以变成代码，权限不再是写在制度手册里的一句话，是机器强制执行的门；红线不再靠人自觉，是系统里过不去的墙。这叫策略即代码，一种韦伯没有的、可执行的科层。

于是有了我开头讲的那套，00-Global 那样的宪法层，成文的、机器可读的规则和身份，加 Harness-Exchange 那样的流动层，高频的任务和交接。规则和事件被物理地分开。这不是我一个人的发明，是任何一个认真跑多 agent 的人，迟早都会被逼出来的结构。而且它是被痛逼出来的，不是设计出来的。我一开始把规则和任务堆在一起，结果规则被日常噪声淹没、agent 读到过期指令，正是这种混乱，逼出了稳定的规则必须和高频的事件分家。这恰恰是最有说服力的地方，它不是一个理论上优雅的架构，是一个真实系统踩了坑之后演化出来的活结构。

---

把这条线捋到底，新原则就是，一个人机组织要分成两层，稳定的宪法层和高频的流动层。

宪法层放那些几乎不变的东西，身份、角色、权限、路由、红线、唯一权威源。它变得慢、改得少、权威高，是整个组织的该信谁、谁说了算、什么绝对不许。流动层放那些每天都在变的东西，任务、状态、交接、回执，它高频流动、随时更新，但碰不到宪法层。

为什么必须分。因为不分就是我一开始踩的那个坑，高频的事件会淹没稳定的规则。当每天几百条任务和几条百年不变的红线堆在一起，agent 分不清哪个是当天的杂事、哪个是不可违背的宪法，于是要么被噪声带偏，要么读到过期的指令。分层，是让规则的稳定和事件的高速各得其所，宪法层保证组织不漂移，流动层保证组织能高速跑。

这里藏着一个和上一章呼应的关键点，用大师卡那句话说，权威可以自动化，但问责不能无主。你可以把规则写成代码、让 agent 在规则内自动行动，权威就自动化了，但每一个机器职位背后，都必须有一个有名有姓的人类或机构主体、一个撤销机制、一份足以重构它所有动作的记录。韦伯的官僚是人，能被问责；agent 不能承担道德和法律责任，所以问责必须显式地挂在某个人身上。科层可以由机器来跑，但责任的锚，永远是人。

---

要把一个人机组织搭成双层，先分清什么进哪一层。

| | 宪法层（00-Global 式） | 流动层（Harness-Exchange 式） |
|--|------------------------|------------------------------|
| 放什么 | 身份、角色、权限、路由、红线、唯一权威源 | 任务、状态、交接、回执、当天的活 |
| 变化频率 | 极慢（改一条要慎重） | 极快（每天几百条） |
| 谁能改 | 只有最高权限（改宪法要走正式流程） | 任何被授权的 agent 或人都能推任务 |
| 形态 | 成文加机器可读，尽量策略即代码 | 事件流、状态机、交接协议 |
| 冲突时 | 以宪法层为准 | 服从宪法层 |
| 问责 | 每个机器职位挂一个有名有姓的人类主体、撤销机制、完整日志 | 每笔交接可追踪、可验收、可追责 |

判定一个东西该进哪层，就问一句，它是几乎不变的规则，还是每天都在变的事件。分错了，组织不是漂移，就是僵化。

---

双层组织解决了规则和事件怎么各就各位。宪法层立好了规矩，流动层跑起了任务。但一个更根本的问题浮出来，你怎么知道流动层里跑出来的那些成果，是真的好，还是只是看起来好。

一个 agent 一周产出一千个东西，每个都格式工整、逻辑自洽、图文并茂。可漂亮的外表，恰恰可能盖住里面的错误。三个办公 agent 拿到同一份销售数据，算出来的季度总额能差出一半还多，而每一份的 PPT 都做得无可挑剔。这就把我们带到绩效这个最古老的管理难题，在 agent 时代最锋利的那一刀，当产出可以无限、可以精美，你到底该信什么。下一章，看绩效怎么从看 KPI 数字，逼进到看证据链。
