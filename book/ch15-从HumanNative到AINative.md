# 第 15 章　从 Human Native 到 AI Native

先讲一个差点被写成反面教材的公司，Meta。

第 2 章讲过它，2025 年六个月内四次重组 AI 部门，人才出走、模型翻车、扎克伯格亲口承认没达预期。当时看，这就是一个堆钱堆人堆算力也堆不出组织的翻车现场。但故事没停在那儿。

2026 年，Meta 推出了一个叫 Muse 的个人 AI agent，能替你发邮件、订行程、买东西、管日程，据报道发布后一度冲到应用商店前列，还在 Connect 大会上扩展到了眼镜等随身设备。而在同一段时间里，Meta 的股价从 2026 年 3 月的低点一路显著回升，涨幅相当可观。

于是 Meta 这个案例，从翻车定格，变成了一条表面上完整的转型弧线，激进重组、触底、修正、回升。这看起来像《大象能否跳舞》式的真实转型，不是一路凯歌，是摔了、痛了、改了、爬起来。

但这里必须极其冷静，这也是这一章的引子。股价回升，绝不等于 Meta 的组织问题解决了。更诚实的说法只能是编年式的，Meta 重组了 AI、出了个爆款产品、随后股价回升了。至于股价为什么涨，同期还有广告主业、资本回报、大盘走势、市场对 AI 变现的整体预期在一起起作用，谁也没法把功劳单独记在 AI Native 转型成功头上。把股价反弹当成转型成功的证据，恰恰是本书要提防的那种归因幻觉。

这就带出本章的核心问题，一家公司从人主导走向 AI 主导，到底是一条什么样的路，它有没有可能，一边看着风光，股价、发布会、漂亮数字，一边其实掉进了一个更深的陷阱。回答这个，要请出一位专门研究组织怎么在守成和探索之间平衡的人。

---

1991 年，斯坦福的詹姆斯·马奇写了一篇后来被引用了几万次的短文，讲一个组织永恒的两难，探索与利用。

利用，是把已知的能力打磨得更精、更快、更省，refinement、efficiency、execution，它的回报快、确定、看得见。探索，是试新的、冒险的、没走过的路，search、experimentation、discovery，它的回报慢、不确定、常常是负的，因为大部分探索会失败。

马奇揭示了一个残酷的机制。因为利用的反馈又快又清楚，而探索的反馈又慢又常常是坏消息，一个只顾适应的组织，会自然而然地偏向利用、荒废探索。短期看它越来越高效，长期看它把自己锁死在一条越走越窄的老路上，马奇管这叫组织可能在短期有效、却长期自毁。用他的话说，探索的本质是对新可能性的试验，它的回报不确定、遥远，而且常常是负的。马奇留下的智慧是，一个组织必须刻意保护探索，保留足够的异质性、冗余、松弛、受保护的实验空间，别让高效这台机器把所有多样性都碾平。

但马奇研究的探索和利用，都是人在做的，是人的注意力、人的资源、人的学习，在两者之间分配。现在，agent 把这两件事的成本都改写了。

---

马奇那个探索与利用的张力，在 agent 时代非但没消失，反而成了每个 AI 转型都要面对的核心决策。

一家公司用 agent，天然会偏向利用，因为 agent 最擅长、反馈最快的，就是把已知的流程做得更快更省。而 agent 帮你做探索，试新方向、找新可能，价值反而更难被看见、更难被度量。马奇那句组织会自然偏向利用、荒废探索，在 agent 时代成了一记精准的警告。

但 agent 给这个老张力加了一个马奇没见过的危险维度。agent 大幅降低了利用的成本，它能把已知流程自动化、规模化，快到极致、省到极致。表面看它也降低了探索的成本，能快速生成方案、跑模拟。于是有了那条从人主导到 AI 主导的进化曲线，这本书开头那份图画的就是它，Human Native，人是执行和决策的主体，到 Half and Half，agent 进入人的工作流，出现人管 agent 的中间态，到 AI Native，大多数可验证的执行由 AI 完成，人只在关键节点决策。

但这条曲线上藏着一个陷阱。回到 Meta，股价回升、Muse 走红，看起来像 AI Native 转型成功，可这更可能是在利用这个维度上的胜利，一个爆款产品、一波市场预期，未必是组织真的理顺了。反过来看 Stripe，它的 AI 能落地，靠的是多年积累的机构就绪度，稳定的内部接口、写作文化、标准环境，而非某个爆款撑场面。真正的 AI Native，是一种深层的组织就绪，一张漂亮的成绩单替不了它。一家公司完全可能一边收获着利用的漂亮数字，一边组织的探索能力和判断力储备正在被悄悄抽干，这就是自动化的能力陷阱。

马奇让我们刻意保护探索，agent 时代要把这件事，从人的注意力分配，升级到机器认知的组合管理。

---

把这条线捋到底，就需要重新定义 AI Native，并守住探索。新原则有两句。

第一句，重新定义 AI Native。它的终点不是无人企业。它的终点是大多数可验证的执行由 AI 完成，人被从持续执行里挪出来，集中到高杠杆的判断点，目标、价值、例外、责任。从 Human Native 到 AI Native，变的不是人少了，是人待的位置变了，从每天执行，挪到关键时刻判断。就像本书开头那个凌晨三点的故事，agent 做了所有的调查和交叉验证，人只做了一个决定。那个人没有消失，他被挪到了最高杠杆的那一点上。

第二句，守住探索，避免能力陷阱。别让 agent 把整个组织都变成一台高效的利用机器。要刻意保护一个机器认知的组合，把探索型 agent 和生产型 agent 分开，让模型和提示保持多样，保护那些不合群的假设，给实验性行为设一道晋升门，再让它变成组织的标准做法。

为什么。因为 agent 有一个人没有的危险能力，它能把一个发现瞬间复制到整个组织，一夜之间抹平多样性。马奇担心的过度利用导致自毁，在 agent 时代会发生得更快，一个高效但错误的做法，能以机器的速度，被复制成整个组织的唯一做法。用大师卡那句话说，当 agent 让利用变得毫不费力，探索就必须被保护，免于被成功本身吞噬。

所以真正的 AI Native 企业，标志不是用了多少 agent，而是两条，人是不是被挪到了高杠杆的判断点上，以及组织有没有在一片自动化的高效里，刻意保住了探索的火种。

---

一家公司想知道自己在从 Human Native 到 AI Native 的曲线上哪个位置、有没有掉进能力陷阱，体检这几项。

| 维度 | 问什么 | 陷阱信号 |
|------|--------|---------|
| 人的位置 | 人还在做重复执行，还是被挪到了判断点？ | 人只是变成了 agent 产出的人肉审核流水线 |
| 机构就绪度 | 能力、流程、规则有没有暴露成 agent 能用的稳定接口？ | 靠一个爆款撑门面，底层没就绪，对照 Stripe 的多年积累 |
| 利用与探索 | 资源是不是全压在把已知做快上？ | 探索型的活全被砍，组织只剩高效的老路 |
| 多样性 | 模型、提示、方法是不是被一个最优解抹平了？ | 一个发现被瞬间复制成全组织唯一做法 |
| 成绩单与组织 | 漂亮数字背后，组织判断力在增强还是萎缩？ | 股价、产量涨，但探索能力和人的判断力在枯竭 |

这张体检表的用意，是戳破 AI Native 等于用了很多 AI 这个幻觉。真正的 AI Native，是人挪对了位置、组织守住了探索，而不是一张被自动化催肥的、漂亮却脆弱的成绩单。

---

AI Native 把人挪到了高杠杆的判断点。但顺着这个逻辑往下推，会推到一个更远的地方。如果 agent 能承接越来越多的执行，如果能力可以被打包、被复用、被跨边界地调用，那么公司这个把人和资源圈在一起的容器，还需要长成现在这个样子吗。

一家研究公司可以只有十个核心，芯片、算力、分发全靠合约从别处接来。一项能力可以从内部 agent、外部 agent、数据服务、人类专家里临时拼装。当协调的成本趋近于零，公司的边界，会不会正在从一道墙，变成一层可以调节通透性的膜。下一章，回到九十年前科斯问的那个最根本的问题，公司为什么存在，看它在 agent 时代会被改写成什么样。
