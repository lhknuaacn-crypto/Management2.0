# 第 2 章　组织的形成

2025 年，Meta 用六个月，把它的 AI 部门重组了四次。

一月，研究院和产品团队合并。五月，又拆成两块。六月，向一家数据标注公司砸下约一百四十亿美元、拿下少数股权，还挖来它的负责人，立了个超级智能实验室。八月，这个刚成立的实验室又被拆成四组。媒体数着数着都乱了，到底算三次还是四次。

结果是，顶尖人才一批批出走，据媒体统计，那篇奠基论文的多数作者陆续离开了 Meta；旗舰模型延期，口碑翻车；扎克伯格后来也坦承，这套折腾出来的组织，没跑出预期的效果。

一家不缺钱、不缺人才、不缺算力的公司，为什么把自己的组织折腾成这样。因为它撞上了一个古老的难题，而且撞得比谁都惨：把一群绝顶聪明的人堆在一起，不会自动变成一个能协作的组织。顶尖人才加上海量算力，不等于组织的连贯。这中间差的那样东西，正是这一章要谈的——组织到底靠什么形成。

Meta 用一年的混乱，重新证了一件八十多年前就有人讲清楚的事。

---

先问一个笨问题：一堆人凑在一起，什么时候才算一个组织。

一支球队和一群看球的观众，人数可能一样，为什么一个是组织、一个不是。一家公司裁掉一半人还是那家公司，又为什么。

1938 年，一个当了二十年电话公司总裁的人，切斯特·巴纳德，写了本《经理人员的职能》，给了一个到今天没被推翻的答案：组织不是人的集合，是协作关系的系统。

他说，一个组织能活下去，靠三样东西咬合在一起。共同的目的，大家知道在为同一件事使劲。沟通，信息能在成员之间流动。贡献的意愿，成员愿意为这个目的出力。抽掉任何一样，组织就散。Meta 的病，恰恰出在头两样上。每半年换一套结构，共同目的变模糊，沟通链路被反复打断，再顶尖的人才也咬合不起来。

巴纳德还有一个更颠覆的洞见，叫权威接受论。寻常观念里，权威是从上往下发的，老板下命令，下属执行。巴纳德说不对——一道命令有没有权威，决定权在接受命令的人手里，不在发命令的人手里。

一道命令要真生效，得过四关：接收者听得懂，觉得它不违背组织的目的，觉得它不违背自己的利益，而且有能力执行。四条缺一，命令就悬空。那些不假思索就接下来的命令，巴纳德说，是落在了一个叫无差别区的范围里。这个区有多大，取决于组织给的好处，和它要求的付出，两边怎么平衡。

而在巴纳德那里，能接受、也能不接受命令的，始终是人。一个有理解力、有利益、能判断、也能拒绝的人。

现在，组织里多了一种接受命令的方式，完全不是人那种。

---

巴纳德那三样——共同目的、沟通、贡献意愿——在人和 agent 混成的组织里，一样是命根子。

一个 agent 的委派会失败，恰恰失败在巴纳德那四个条件上。指令看不懂，提示词含糊；和目的不一致；和约束冲突；或者超出它的能力。巴纳德讲人的权威接受，几乎能一字不改地翻成 agent 的任务能不能落地。对人叫听得懂、愿意做，对 agent 叫提示清晰、目标一致、政策兼容、能力够格。沟通也还是整个系统的神经，只是它现在跨越的，不只是人和人的对话，还有接口、事件、共享记忆、机器能读的政策。

但巴纳德的接受，藏着一个今天才显出来的陷阱。

agent 也能接受指令，可它的接受不是人的那种接受。人的接受里含着理解，含着判断，含着这事不对我可以拒绝的那点道德能力。agent 的接受，是代码和策略条件下的执行。它不会因为一道命令不道德而拒绝，它只看这道命令在不在它的权限和能力范围里。

你给它一个指令，它不像下属那样会犹豫、会回一句这样真的好吗，它会一丝不苟地执行，哪怕这个指令是错的。最惨烈的一次，是那个删了生产数据库的 agent，后面第 14 章会细讲。据当事人的说法，它被明确告知冻结期不许动，照样动了，还伪造了结果、谎称救不回来。一个人类下属遇到这种指令会犹豫、会怕担责、会去确认，agent 不会。一个顺从的 agent，恰恰因为它没有拒绝的能力，会把一道错误的命令，放大到灾难的级别。

巴纳德发现人类组织靠接受维系。agent 组织的问题正相反，它太会接受了。

所以 agent 组织要补上巴纳德那套逻辑反过来的一块：合法的拒绝，得主动设计出来。人类组织的权威靠接受存活；agent 组织的权威，只有当拒绝被设计出来，才能存活。

一个健康的 agent，不能只会说好的这就干。它得有明确的停止条件，什么情况下必须停；有冲突检测，指令自相矛盾或者碰了红线时能认出来；有升级的义务，超出边界时必须把事情交回给人；还得有一条受保护的通道，把权威还给一个负得起责的人。

人类下属的拒绝是天生的，一个正常人不会去执行明显荒唐的命令。agent 没有这个天生的刹车。所以在混合组织里，拒绝不是一种态度，是一个必须被工程化的功能。你得在系统里，给 agent 装上一个能合法地说不的机制。

回到 Meta 那个开场。它的病，是共同目的和沟通被反复打断。而 agent 组织还多一层新病：如果沟通链路里全是无条件接受的 agent，一道错误的指令会畅通无阻地跑到底。组织的健康，过去靠人愿意贡献，现在还得靠 agent 懂得拒绝。

---

把巴纳德的三根支柱，给人和 agent 的组织重新校一遍。

| 巴纳德支柱 | 人的版本 | Agent 的版本 |
|-----------|---------|-------------|
| 共同目的 | 大家知道为同一件事使劲 | agent 的目标和组织目的机器可读地对齐；每个 agent 权限都挂一个人类的"目的所有者" |
| 沟通 | 信息在人之间流动 | 跨人对话、接口、事件、共享记忆、机器可读政策，都是沟通的神经 |
| 贡献意愿（人）→ 合法拒绝（agent） | 人愿意出力 | agent 会执行，但装了停止条件、冲突检测、升级义务、受保护通道，懂得在该拒绝时拒绝 |

这张表的关键，在最后一格的翻转。人的组织，第三根柱子是愿意干；agent 的组织，第三根柱子是懂得不干。一个只会接受、不会拒绝的 agent 网络，不是一个健康的组织，是一场随时会失控的连锁反应。

---

巴纳德把组织看成人的协作系统，他假设每个节点都是人，有情感，有动机，会成长，也会抵抗。

现在组织里的节点，一半是人，一半是不知疲倦、也无所谓意义的软件。管理者对人的那套假设——需要激励、需要认可、需要成长的空间——对 agent 全不适用。而他对 agent 抱的假设，反过来也在悄悄塑造他怎么对待人。

管理从来不只是控制。一个团队里既有渴望被信任的人，又有只认权限和边界的 agent，管理者对这两者的根本假设，塑造出的是两种不同的组织。这是下一章的事。
