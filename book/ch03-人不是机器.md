# 第 3 章　人不是机器

2025 年底，Anthropic，一家做出顶级 AI 的公司，把自己的员工拉来做了一次内部研究。132 个工程师和研究员填了问卷，53 个做了深访，再加上对二十万条内部 Claude Code 使用记录的分析。

这是一份少见的诚实报告。它没讲我们的 AI 多厉害，讲的是用了 AI 之后，这些人身上发生了什么。

有几条，看了让人心里一沉。有人说，他现在八九成的问题都去问 Claude，不问同事了。有资深工程师发现，年轻人来问他的问题越来越少，因为 Claude 答得更快，还不用看人脸色。那种老带新、边干边教的师徒关系，在悄悄消失。还有人担心，自己越来越不读文档、不手动调试、不去建立对系统的深层理解，手上的功夫在生疏。更有人开始焦虑：我到底是在用 AI，还是在帮 AI 把我自己训练成多余的。

这不是哪个反 AI 的人在唱衰。这是造 AI 的公司，研究自己的员工，得出的结论。

一群绝顶聪明、待遇优厚、技术领先的人，在最理想的条件下用最好的 AI，报告出来的却是协作退化、师徒断裂、技能萎缩、身份焦虑。这说明一件事：人加 agent，不是简单给人配了个好用的工具，它在重塑人本身。而怎么重塑，取决于一个很深的东西——你对人、对 agent，到底抱着什么假设。

---

1960 年，麻省理工的道格拉斯·麦格雷戈写了本《企业的人性面》，提出了管理学里最有名的一对假设，X 理论和 Y 理论。

X 理论假设，人天生厌恶工作、能躲就躲、必须被驱使和威胁、逃避责任、只求安稳。Y 理论假设，人付出努力像休息和玩耍一样自然、能自我引导、会主动担责、创造力被严重低估了。

麦格雷戈最狠的一笔在后头。他指出，你信哪一种，你就会造出一个验证它的现实。

一个管理者若信 X 理论，他就会设计出严密的监控、细碎的考核、层层的审批。在这套制度下，员工果然变得被动、推诿、只做被要求的最低限度。制度制造了它所假设的那种人。反过来，信 Y 理论的管理者，会给空间、给信任、给自主，员工果然表现出主动和创造。他有两句话，一句是，人在工作中付出体力和脑力，就像玩耍或休息一样自然；另一句是，普通人的智力潜能，只被利用了一部分。

比他早几十年，玛丽·帕克·福列特说过一句更漂亮的话。她说，管理的问题从来不在控制人，而在人怎么一起把局面驾驭起来。她把这叫 power-with，共同生长出驾驭局面的能力，区别于一个人压过另一个人的 power-over。

但麦格雷戈和福列特谈的，都是人。一个有尊严、要意义、渴望成长的人。

现在，团队里坐进来一个不要尊严、不求意义、也无所谓成长的东西。

---

麦格雷戈那条假设变成现实的铁律，意外地也适用于 agent。

你对 agent 的假设，也会变成架构。一个团队若打心底认为 agent 就是个不靠谱的高级自动补全，他们就只敢派给它最琐碎的活，收获的也只有琐碎的价值，这是 X 理论的自我实现。反过来，一个团队若盲目相信 agent 无所不能，就会给它不该给的自主权，造出不安全的系统，同样是假设制造了现实。福列特那句一起控制局面在这里也成立。人机混合团队最好的状态，是人和 agent 一起去驾驭一个双方都看得清的局面，agent 拓宽事实、生成方案，人来判断和拍板，而不是人在旁边一道道指挥 agent。

但这里藏着一个要命的诱惑：把管人的那套，直接套到 agent 身上。

agent 越来越像人了。它会对话，会思考，有记忆，能协作。这种像人的外表，诱着我们下意识用管人的假设去管它，比如信任它、给它空间、它会成长。于是有了越来越像同事的 agent，有名字，有角色，能聊天。Anthropic 内部那些工程师，面对的就是这样的 agent，它像一个随叫随到、无所不知的同事，好用到大家宁可问它，不问身边的人。

而结果，就是开头那份报告。当 agent 像同事一样好用，人就真把它当同事了。那些低效却珍贵的东西——师徒传承、共同解题、随口一问建立的信任——被悄悄替换掉了。一个被 agent 正确回答的问题，省了时间；可它也消灭了一次本可以传递判断、建立关系、积累默契的人类互动。

麦格雷戈的 Y 理论对人是解药。但把 Y 理论直接用到 agent 身上，是毒药。因为 agent 不需要信任带来的成长，它需要的是与它能力相匹配的、可撤销的授权。

---

人的动机，和机器的能动性，是两回事，得分开。对人，用 Y 理论；对 agent，用校准的授权。

管人，靠相信他们的潜能，给信任、给空间，人会成长起来。管 agent，靠他们潜能的证据，按已经被证明的能力、按后果可不可逆、按行为可不可观测，一格一格地放开授权。

这不是信任，是校准。你不会因为一个 agent 看起来很能干就给它更大的权限，你只会因为它在这个具体任务上反复被验证过、做错了也兜得住，才多放一格。agent 不会因为你信任它而士气高涨，它只会在你划定的能力边界里，忠实地执行。一句话，管人靠相信他们的潜能，管 agent 靠他们潜能的证据。

这里有一条必须守住的底线，也是这一章最要紧的话：别让对 agent 的高效，偷走对人的滋养。Anthropic 那份报告是一记警钟。当 agent 接手了越来越多的低层工作，那些低效的人类互动——新人问老人、同事一起卡壳、边干边学——会自然萎缩。而恰恰是这些互动，在传递判断、信任、身份和默契。一个只优化 agent 效率、不呵护人成长的组织，短期更快，长期会失去它的判断力储备。因为今天在萎缩的那些技能，正是明天监督 agent 所必需的。

---

管一个混合团队，最容易犯的错，是用一把尺子去量两种东西。分开。

| | 对人 | 对 agent |
|--|------|---------|
| 根本假设 | Y 理论：人会自我引导、会成长 | 校准授权：按证据放权，不按印象 |
| 给什么 | 信任、空间、意义、成长 | 与能力匹配的、可撤销的权限 |
| 怎么放权 | 相信在前，表现在后（激发潜能） | 表现在前，放权在后（验证能力） |
| 要警惕的 | 别用管 agent 的冷冰冰去管人（KPI 化、监控化） | 别用管人的温情去管 agent（它会成长的幻觉） |
| 底线 | 护住师徒、共同解题、随口一问，这些是判断力的苗圃 | 别让 agent 的高效，抽干上面那个苗圃 |

这张表的核心是不混用。对人越像 Y 理论越好，对 agent 越靠证据越好。混用的代价，是既伤了人，又误判了机器。

---

麦格雷戈让我们看清，管理者对人的假设塑造了整个组织。福列特让我们看清，管理是一起控制局面。这两位都在教我们怎么对待执行者。

但他们有一个共同的、从没被质疑过的前提：执行者是人。他们关于动机、权威、协作的全部智慧，都建在对面坐着的是一个人之上。

现在，对面坐着的，有一半不是人。它会干活，会协作，甚至会拒绝，但它不要尊严，不求意义，可以被复制，可以被关掉。

所以在接着用管理学的老概念校准之前，得先停下来，认清这个新执行者到底是什么。它不是数字人，不只是工具，是一个我们还没有现成的词去命名的东西。第二部就从认清它开始。
