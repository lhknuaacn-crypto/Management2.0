# 第 3 章　人不是机器

2025 年底，Anthropic，一家做出顶级 AI 的公司，把自己的员工拉来做了一次内部研究。132 个工程师和研究员填了问卷，53 个做了深访，再加上对二十万条内部 Claude Code 使用记录的分析。

这份研究记录的重点，是员工使用 AI 后的工作变化。

研究中，有员工称自己现在会把多数问题先交给 Claude，而不是同事。一些资深工程师也注意到，年轻同事来请教的次数减少了。受访者还提到，他们担心自己少读文档、少做手动调试后，对系统的理解会变浅。这些是员工的观察和担忧，研究并不能据此证明师徒关系或技能已经普遍退化。

Anthropic 研究的是自家员工和内部工具，不能代表所有组织。但这项研究提出了一个实际问题：当员工习惯先向 Agent 求助，组织怎样保留同事之间的交流、传授和共同判断？答案与管理者如何理解人和软件有关。

---

1960 年，麻省理工的道格拉斯·麦格雷戈写了本《企业的人性面》，提出了管理学里最有名的一对假设，X 理论和 Y 理论。

X 理论假设，人天生厌恶工作、能躲就躲、必须被驱使和威胁、逃避责任、只求安稳。Y 理论假设，人付出努力像休息和玩耍一样自然、能自我引导、会主动担责、创造力被严重低估了。

麦格雷戈指出，管理者的假设会影响制度设计，而制度又会影响员工的行为。

一个管理者若信 X 理论，他就会设计出严密的监控、细碎的考核、层层的审批。在这套制度下，员工果然变得被动、推诿、只做被要求的最低限度。制度制造了它所假设的那种人。反过来，信 Y 理论的管理者，会给空间、给信任、给自主，员工果然表现出主动和创造。他有两句话，一句是，人在工作中付出体力和脑力，就像玩耍或休息一样自然；另一句是，普通人的智力潜能，只被利用了一部分。

比麦格雷戈早几十年，玛丽·帕克·福列特讨论过 power-with 与 power-over 的区别。前者指共同处理问题的能力，后者指一方把意志压到另一方身上。

但麦格雷戈和福列特谈的，都是人。一个有尊严、要意义、渴望成长的人。

如今，团队里还多了软件执行者。它可以处理任务，却没有人的尊严、意义感和成长需求。

---

麦格雷戈关于管理假设影响制度的观点，也能帮助我们分析 Agent 的管理方式。

管理者对 Agent 的判断会影响任务分配和权限。若把它当成不可靠的自动补全，可能只交给它琐碎任务；若把它当成无所不能的执行者，又可能授予过多权限。福列特讨论的共同处理问题，在人机团队里也有参考价值：Agent 可以搜集材料、生成方案，人负责判断目标和承担决定。

但管理者不能把对人的假设原样套在 Agent 身上。

Agent 会对话、保留记忆并参与协作，因此容易被当作同事来对待。Anthropic 的员工研究记录了这种使用习惯：一些工程师更愿意先问 Claude，而不是身边的同事。

报告提出了这种便利可能带来的代价。员工向 Agent 提问，节省了等待时间；如果他们因此减少向同事请教，也可能少了交流判断、传授经验和建立合作关系的机会。

Y 理论强调给人信任和自主空间。Agent 没有人的成长需求，授权应与其在具体任务上的能力相匹配，而且能够撤销。

---

人的动机与软件的执行能力不同，管理方式也要区分。对人，可以运用 Y 理论；对 Agent，则应按证据校准授权。

管人，靠相信他们的潜能，给信任、给空间，人会成长起来。管 agent，靠他们潜能的证据，按已经被证明的能力、按后果可不可逆、按行为可不可观测，一格一格地放开授权。

给 Agent 扩大权限，需要看它在具体任务上的表现、错误能否被发现，以及后果能否补救。对人的潜能可以先给空间，再看成长；对 Agent，应先积累执行证据，再决定是否放权。

组织还要留意 Agent 对员工学习的影响。新人请教同事、团队一起排查问题，虽然耗时，却能传递经验和判断。如果这些交流持续减少，员工监督 Agent 所需的专业能力也可能跟着变弱。使用效率之外，组织还应观察员工是否仍有机会学习和共同解决问题。

---

管一个混合团队，最容易犯的错，是用一把尺子去量两种东西。分开。

| | 对人 | 对 agent |
|--|------|---------|
| 根本假设 | Y 理论：人会自我引导、会成长 | 校准授权：按证据放权，不按印象 |
| 给什么 | 信任、空间、意义、成长 | 与能力匹配的、可撤销的权限 |
| 怎么放权 | 相信在前，表现在后（激发潜能） | 表现在前，放权在后（验证能力） |
| 要警惕的 | 别用管 agent 的冷冰冰去管人（KPI 化、监控化） | 别用管人的温情去管 agent（它会成长的幻觉） |
| 底线 | 护住师徒、共同解题、随口一问，这些是判断力的苗圃 | 别让 agent 的高效，抽干上面那个苗圃 |

表中两列不能互换。用权限和监控替代对人的信任，会伤害员工；用对人的信任替代 Agent 的能力验证，则会造成错误授权。

---

麦格雷戈讨论管理假设怎样影响员工行为，福列特讨论人们如何共同处理问题。

他们讨论的执行者都是人。Agent 进入团队后，组织还需要判断哪些理论可以延用，哪些需要另作设计。

Agent 可以执行任务和参与协作，但它没有人的尊严、意义需求和责任能力，也可以被复制或关闭。

要讨论管理方式，先要辨认这种执行者的能力和边界。第二部从 Agent 的形态开始。
