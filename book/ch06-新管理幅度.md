# 第 6 章　新管理幅度

管理学里有一个用了几十年的数字：一个经理能有效管的下属，大约五到七个。这叫管理幅度。超过这个数，他就顾不过来，开不完的一对一、对不齐的信息、漏掉的问题。军队按这个数编班排，公司按这个数画组织架构图。

把这个经验值放到 Agent 工作场景里，问题就变了。

一些从业者的经验是，一个工程师同时监督三到五个高交互的编码 Agent 会话，已经很吃力。更多会话会让人难以跟踪任务进度、及时批准操作或发现偏离。这个范围是实践经验，不是公开实验得出的统一上限。学界对自主系统监督的研究也发现，可管理数量取决于任务耦合度、打断频率和 Agent 的自治程度。

三到五个 Agent 与传统的五到七名下属，看起来相近，但两者不是同一种管理负荷。Agent 数量不能直接换算成人数；更要紧的是每个执行任务需要多少监督和介入。

---

要谈经理到底在管什么，绕不开亨利·明茨伯格。

1973 年，管理学界还信着法约尔那套，经理的工作就是计划、组织、协调、控制，一个坐在办公室里冷静运筹的人。明茨伯格通过跟随经理工作，记录他们一天的实际活动。

他的观察与教科书里的经理形象不同。经理的工作经常被电话、短会、临时问题和沟通打断。明茨伯格提醒读者，经理描述的工作和他们实际花时间做的事情并不总是一致。

明茨伯格把经理的工作归纳为十种角色，分为三类：人际类，挂名头领、领导者、联络人。信息类，监测者、传播者、发言人。决策类，企业家、危机处理者、资源分配者、谈判者。这些角色彼此关联：正式权力带来人际关系，人际关系又带来信息，信息支持决策。

明茨伯格观察的经理管理的是人。Agent 进入团队后，经理还要处理权限、自动执行和升级机制。

---

明茨伯格的十种角色可以帮助管理者拆分工作，判断哪些任务可交给 Agent，哪些仍需要人的判断。

Agent 可以监测信号、分发信息、按规则分配资源，也能处理部分例行问题。对外发言、谈判和危机处置则需要明确的授权边界。十种角色可以在人与 Agent 之间重新分配。

任务拆分后，监督负荷也随之改变。

Agent Harness 允许多个 Agent 并发运行。以 Grok Bot 为例，一组分工明确的 Bot 可以并行处理任务并相互交接。管理者面对的对象从单个会话扩展为多条同时运行的执行回路。

高交互的 Agent 会占用人的注意力。限制因素不一定是模型能力，而是监督者能否及时发现卡顿、偏离或需要批准的操作。管理者要计算的是同时需要关注的自主执行回路。

因此，管理幅度可以从下属人数扩展为可安全监督的自主执行回路数。一个人能带一百个 agent 吗，能，前提是这一百个大部分时候不用他盯，它们跑在有界的、可自动验证的回路里，只在真正需要判断的关口才升级给他。一个人只能带三个 agent 吗，也对，如果这三个每个都在做高风险、需要连续盯防的活。决定管理幅度的，是每条回路要占用多少人的注意力。

---

明茨伯格的角色分类还揭示了另一个问题：能力不等于授权。

Agent 可以执行许多管理角色中的任务，例如整理信息、分配资源或处理例行问题，但执行能力不等于组织授权。它可以生成对外回复，却未必有权代表公司作出承诺；也可以按规则调度资源，却不一定能判断其中的组织后果。

因此，角色能力和角色授权需要分别定义：前者说明 Agent 能完成什么，后者说明它可以代表组织决定什么。

每一个交给 agent 的角色，都得配四样东西。一个明确的授权级别，它能自己做到哪、哪里必须停。一个身份信号，让人和系统知道现在在跟一个 agent 打交道、它有多大权。一条承诺边界，它能替组织承诺什么、不能承诺什么。一个人类回接点，超出边界时权力交回给谁。

Agent 能执行某些管理任务，并不意味着它可以继承经理的职位或权限。

明茨伯格的十种角色可以转化为一张人机分工表，标明每项工作的执行者、授权范围和交接方式。管理者要设计的是这些职责如何分配，而不是简单地增加 Agent 数量。

---

传统管理幅度问你带几个人。混合组织要改问你能安全盯住几条回路。启动一个多 agent 单元前，逐条算。

| 要素 | 算什么 |
|------|--------|
| 回路数 | 同时在跑的自主 agent 回路有几条？ |
| 单条注意力占用 | 每条回路平均要占用人多少注意力？（连续盯防 / 关卡批准 / 只管异常 / 事后抽查） |
| 风险权重 | 这条回路做错的后果多大？（可逆 / 不可逆 / 涉及钱、法律、安全） |
| 升级带宽 | 出了异常，人能不能及时接住？升级路径清不清楚？ |
| 实际幅度 | 不是回路数，是注意力总占用除以人的可用注意力，超过 1 就管崩了 |

这张表把监督负荷转化为可估算的项目。若要扩大管理幅度，应先降低每条回路占用的注意力，并提高自动验证能力、减少异常，再考虑增加 Agent。

---

明茨伯格描写的经理通过人际关系获得信息，再据此作出决策。Agent 已经能够承接部分监测、传播和分配工作，信息也可以绕过传统岗位直接流转。

如果信息和任务可以在 Agent 之间直接流转，传统岗位和汇报线还承担什么作用？下一章讨论组织的基本单元是否会从固定岗位转向围绕结果组建的团队。
